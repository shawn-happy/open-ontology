Branching in Insight

Insight integrates with Global Branching so you can analyze your Ontology and run actions against a branch directly in Insight. Branch context applies to the data you analyze and the actions you run; the Insight workbook itself is not a branchable resource, so you cannot save a workbook while on a branch. Autosave continues to work, so your in-progress analysis is preserved.

For general information on Global Branching concepts and workflows, refer to the Global Branching documentation.

Scope your session to a branch

You can put your Insight session on a branch in the following ways:

  • Branch selector: Use the branch selector in the workbook header or on the home page to switch onto a branch from main.
  • Branch taskbar: When you are already on a branch, the platform branch taskbar appears at the bottom of your screen so you can view and manage your branch context.
  • Branch URL parameter: Open Insight from a link that includes a foundry-branch-rid parameter to load your session already scoped to that branch. Other applications, such as Global Branching, can link to Insight this way.

What is branch-aware

When your session is on a branch, your Insight analysis reflects the branch instead of main, including the workbook, the home page, and any actions you run.

What is not supported on a branch

Some operations that write or export data are not yet branch-aware, so Insight disables them while you are on a branch. Each disabled control includes a tooltip explaining that it is not available on a branch. The following operations are not supported on a branch:

  • Saving a workbook, including the Save and Save as options.
  • Saving a layout.
  • Publishing an object set, or saving one as a list.
  • Exporting to Excel.
  • Opening results in an application that does not support branching.

:::callout{theme="neutral" title="Autosave works even though you cannot save a workbook"} While you are on a branch, Insight autosaves your in-progress analysis, so your work is preserved and you will not lose it if you reload the page or navigate away. This is separate from saving a workbook to your files: you cannot save a workbook as a resource, publish an object set, or save a layout while on a branch. :::

POST /api/v2/checkpoints/records/getBatch

:::callout{theme=warning title=Warning} This endpoint is in preview and may be modified or removed at any time. To use this endpoint, add preview=true to the request query parameters. :::

Fetch multiple checkpoint records in a single request. Records not found or inaccessible to the user will be omitted from the response.

The maximum batch size for this endpoint is 100.

Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:checkpoints-read.

OAuth2 scopes: api:checkpoints-read

Query parameters

参数 类型 必填 说明
preview boolean 否 Enables the use of preview functionality.
示例: true

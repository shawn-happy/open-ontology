GET /api/v2/admin/users/{userId}/providerInfo

Get the UserProviderInfo.

Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:admin-read.

OAuth2 scopes: api:admin-read

Path parameters

参数 类型 必填 说明
userId string 是 A Foundry User ID.
示例: dd05feb8-662a-445d-8f4c-ce92d46bedeb

Response

UserProviderInfo

参数 类型 必填 说明
UserProviderInfo object 是 示例: {"providerId":"2838c8f3-d76a-4e99-acf1-1dee537e4c48"}
UserProviderInfo.providerId string 是 The ID of the User in the external authentication provider. This value is determined by the authentication provider.
At most one User can have a given provider ID in a given Realm.
示例: 2838c8f3-d76a-4e99-acf1-1dee537e4c48		 
{
  "providerId": "2838c8f3-d76a-4e99-acf1-1dee537e4c48"
}

Error responses

错误码 错误名称 说明
PERMISSION_DENIED GetUserProviderInfoPermissionDenied The provided token does not have permission to view the provider information for the given user.
INVALID_ARGUMENT UserDeleted The user is deleted.
NOT_FOUND UserProviderInfoNotFound The given UserProviderInfo could not be found.
NOT_FOUND UserNotFound The given User could not be found.

GET /api/v2/models/liveDeployments

:::callout{theme=warning title=Warning} This endpoint is in preview and may be modified or removed at any time. To use this endpoint, add preview=true to the request query parameters. :::

Lists direct live deployments for the specified Model, optionally filtered by branch. Only direct deployments (those tracking the latest model version on a branch) are returned.

Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:models-read.

OAuth2 scopes: api:models-read

Query parameters

参数 类型 必填 说明
modelRid string 是 The Resource Identifier (RID) of the Model to list live deployments for.
示例: ri.models.main.model.f351c142-0e4c-4b12-adc2-6e1539737ae9
branch string 否 If provided, only return the live deployment associated with this branch.
示例: master
preview boolean 否 Enables the use of preview functionality.
示例: true

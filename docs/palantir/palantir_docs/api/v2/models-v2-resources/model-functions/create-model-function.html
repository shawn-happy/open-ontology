POST /api/v2/models/{modelRid}/function

:::callout{theme=warning title=Warning} This endpoint is in preview and may be modified or removed at any time. To use this endpoint, add preview=true to the request query parameters. :::

Creates a function for the model. If a function already exists for the model, the existing function is updated.

Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:models-write.

OAuth2 scopes: api:models-write

Path parameters

参数 类型 必填 说明
modelRid string 是 The Resource Identifier (RID) of a Model.
示例: ri.models.main.model.f351c142-0e4c-4b12-adc2-6e1539737ae9

Query parameters

参数 类型 必填 说明
preview boolean 否 Enables the use of preview functionality.
示例: true

Request body

{
  "apiName": "myModelFunction",
  "ontologyBinding": "ri.ontology.main.ontology.a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "isRowWise": false,
  "displayName": "Core.DisplayName"
}

Response

ModelFunction

The created ModelFunction

参数 类型 必填 说明
ModelFunction object 是 The created ModelFunction
示例: {"apiName":"myModelFunction","ontologyBinding":"ri.ontology.main.ontology.a1b2c3d4-e5f6-7890-abcd-ef1234567890","isRowWise":false,"functionVersion":"0.0.1","displayName":"Core.DisplayName","functionRid":"ri.function-registry.main.function.a1b2c3d4-e5f6-7890-abcd-ef1234567890"}
ModelFunction.functionRid string 是 示例: ri.function-registry.main.function.a1b2c3d4-e5f6-7890-abcd-ef1234567890
ModelFunction.functionVersion string 是 示例: 0.0.1
ModelFunction.displayName string 是 示例: Core.DisplayName
ModelFunction.apiName string 是 示例: myModelFunction
ModelFunction.isRowWise boolean 是 示例: false
ModelFunction.ontologyBinding string 否 The unique Resource Identifier (RID) of the Ontology. To look up your Ontology RID, please use the
List ontologies endpoint or check the Ontology Manager.
示例: ri.ontology.main.ontology.a1b2c3d4-e5f6-7890-abcd-ef1234567890

Error responses

错误码 错误名称 说明
INVALID_ARGUMENT ModelApiTypeUnsupportedForFunction The model API contains a data type that is not supported for Ontology function creation.
INVALID_ARGUMENT InvalidFunctionApiName The provided API name for the function is invalid.
INVALID_ARGUMENT OntologyBindingRequired An ontologyBinding is required when creating or replacing a model function.
NOT_FOUND OntologyNotFound The specified ontology was not found.
PERMISSION_DENIED CreateModelFunctionPermissionDenied Could not create the ModelFunction.
NOT_FOUND ModelNotFound The given Model could not be found.

Microsoft SharePoint

The Microsoft SharePoint connector is a Palantir-provided driver for Microsoft SharePoint.

To create a new Microsoft SharePoint source, follow the standard setup flow for Palantir-provided drivers, then use the sections below for Microsoft SharePoint-specific configuration and networking.

Microsoft Dynamics NAV

The Microsoft Dynamics NAV connector is a Palantir-provided driver for Microsoft Dynamics NAV.

To create a new Microsoft Dynamics NAV source, follow the standard setup flow for Palantir-provided drivers, then use the sections below for Microsoft Dynamics NAV-specific configuration and networking.

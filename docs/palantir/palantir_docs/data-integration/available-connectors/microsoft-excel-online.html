Microsoft Excel Online

The Microsoft Excel Online connector is a Palantir-provided driver for Microsoft Excel Online.

To create a new Microsoft Excel Online source, follow the standard setup flow for Palantir-provided drivers, then use the sections below for Microsoft Excel Online-specific configuration and networking.

Microsoft SharePoint Excel

The Microsoft SharePoint Excel connector is a Palantir-provided driver for Microsoft SharePoint Excel.

To create a new Microsoft SharePoint Excel source, follow the standard setup flow for Palantir-provided drivers, then use the sections below for Microsoft SharePoint Excel-specific configuration and networking.

Couchbase

The Couchbase connector is a Palantir-provided driver for Couchbase.

To create a new Couchbase source, follow the standard setup flow for Palantir-provided drivers, then use the sections below for Couchbase-specific configuration and networking. For the complete property reference, see the official Couchbase driver documentation â.

Add or update struct field

Supported in: Batch, Faster, Streaming

Updates a field of a struct or adds a new field.

Expression categories: Struct

Declared arguments

  • Expression: Expression to update struct field with.
    Expression\
  • Locator: Locate inner elements with multiple entries like ['author', 'email'].
    StructLocator
  • Struct: The struct to update.
    Expression\

Output type: Struct

Get timestamps for scene frames

Supported in: Batch

Get the timestamps and scene scores for detected scene frame transitions in the video.

Expression categories: Media

Declared arguments

  • Media reference: The video from which scene frame timestamps are extracted.
    Expression\
  • optional Scene sensitivity: Controls how easily scene changes are detected. Higher sensitivity detects more subtle transitions.
    Enum\

Output type: Array\>

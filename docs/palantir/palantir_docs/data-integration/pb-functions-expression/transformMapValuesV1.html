Transform map values

Supported in: Batch

Transforms values of a map by applying an expression to every key-value pair.

Expression categories: Map

Declared arguments

  • Expression to apply: The expression to apply once per key-value pair of the map.
    Expression\
  • Map: Map expression.
    Expression\>

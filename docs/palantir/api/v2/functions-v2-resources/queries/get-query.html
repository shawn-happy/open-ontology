GET /api/v2/functions/queries/{queryApiName}

:::callout{theme=warning title=Warning} This endpoint is in preview and may be modified or removed at any time. To use this endpoint, add preview=true to the request query parameters. :::

Gets a specific query type with the given API name. By default, this returns the highest semantic version of the query, excluding pre-release versions. To resolve the most recently published version instead, including pre-release versions, set latestVersionResolution to PUBLISH_TIME.

Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:functions-read.

OAuth2 scopes: api:functions-read

Path parameters

参数 类型 必填 说明
queryApiName string 是 The name of the Query in the API.
示例: myQueryFunction

Query parameters

参数 类型 必填 说明
version string 否 The version of the given Function, written <major>.<minor>.<patch>-<tag>, where -<tag> is optional.
Examples: 1.2.3, 1.2.3-rc1.
示例: 1.2.3
latestVersionResolution enum 否 Controls how latest version is resolved when version is omitted. Defaults to SEMANTIC_VERSION.
示例: PUBLISH_TIME
includePrerelease boolean 否 When resolving the latest version, whether prerelease versions are considered. Defaults to false,
except when latestVersionResolution is PUBLISH_TIME. Not supported together with version.
preview boolean 否 Enables the use of preview functionality.
示例: true

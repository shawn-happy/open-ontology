GET /api/v2/mediasets/{mediaSetRid}/items/{mediaItemRid}/metadata

Gets detailed metadata about the media item, including type-specific information such as dimensions for images, duration for audio/video, page count for documents, etc.

Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:mediasets-read.

OAuth2 scopes: api:mediasets-read

Path parameters

参数 类型 必填 说明
mediaSetRid string 是 The RID of the media set.
mediaItemRid string 是 The RID of the media item.

Response

MediaItemMetadata

Detailed metadata about a media item, including type-specific information such as dimensions for images,
duration for audio/video, page count for documents, etc.

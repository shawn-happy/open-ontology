GET /api/v2/dataHealth/checks/{checkRid}

:::callout{theme=warning title=Warning} This endpoint is in preview and may be modified or removed at any time. To use this endpoint, add preview=true to the request query parameters. :::

Get the Check with the specified rid.

Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:data-health-read.

OAuth2 scopes: api:data-health-read

Date distribution

Supported in: Batch

Computes the distribution of dates/timestamps in a specified column.

Transform categories: Datetime

Declared arguments

  • Column: Column to compute distribution for.
    Column\
  • Dataset: Dataset to apply distribution to.
    Table
  • End time: End time for distribution. Any time after will be ignored.
    Literal\
  • Start time: Start time for distribution. Any time before will be ignored.
    Literal\
  • Time bucket: The time unit to use for buckets.
    Enum\

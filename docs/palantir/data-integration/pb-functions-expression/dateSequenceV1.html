Date sequence

Supported in: Batch, Faster

Creates an array with dates in range from start to end.

Expression categories: Datetime

Declared arguments

  • End date: The date to end at (inclusive).
    Expression\
  • Start date: The date to start from (inclusive).
    Expression\
  • Step unit: Unit of the step size.
    Enum\
  • optional Step size: The size of the steps between numbers. Defaults to 1.
    Expression\

Output type: Array\

Examples

Example 1: Base case

Argument values:

  • End date: last_planned_flight
  • Start date: first_planned_flight
  • Step unit: DAYS
  • Step size: null

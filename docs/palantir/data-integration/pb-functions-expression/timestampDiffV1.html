Timestamp difference

Supported in: Batch, Faster, Streaming

Returns the difference between two timestamps in the given time unit.

Expression categories: Datetime

Declared arguments

  • End: The end date or time to subtract from.
    Expression\
  • Start: The start date or time to be subtracted.
    Expression\
  • Unit: Time unit.
    Enum\

Output type: Long

Examples

Example 1: Base case

Argument values:

  • End: 2022-10-01T10:00:00Z
  • Start: 2022-10-01T09:00:00Z
  • Unit: HOURS

Output: 1

Example 2: Null case

Argument values:

  • End: End
  • Start: Start
  • Unit: HOURS

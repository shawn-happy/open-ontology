WooCommerce

The WooCommerce connector is a Palantir-provided driver for WooCommerce.

To create a new WooCommerce source, follow the standard setup flow for Palantir-provided drivers, then use the sections below for WooCommerce-specific configuration and networking. For the complete property reference, see the official WooCommerce driver documentation â.

Azure Table Storage

The Azure Table Storage connector is a Palantir-provided driver for Azure Table Storage.

To create a new Azure Table Storage source, follow the standard setup flow for Palantir-provided drivers, then use the sections below for Azure Table Storage-specific configuration and networking. For the complete property reference, see the official Azure Table Storage driver documentation â.

OAuth 2.0 authentication

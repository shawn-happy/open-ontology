## 1. 背景与目标

### 1.1 背景

系统管理是本体语义平台（Prism）的平台级基础功能模块，为整个平台提供用户身份管理、角色权限控制、组织架构维护和操作日志审计能力。作为平台共享功能，系统管理独立于工作空间体系，通过左上角图标栏直接访问。

### 1.2 目标

1. **统一身份认证**：支持用户名、手机号、邮箱三种方式 + 密码登录，提供初始超级管理员账号。
2. **细粒度权限控制**：菜单 + 按钮两级权限体系，按钮权限标识与后端接口鉴权一一映射。
3. **组织架构管理**：无限层级部门树，支持用户分配与部门负责人设置。
4. **全面操作审计**：覆盖审计日志、登录日志、执行日志三类日志，支持追溯与导出。

## 2. 用户角色与使用场景

| 角色 | 典型操作 | 使用场景 |
|---|---|---|
| 超级管理员（admin） | 管理所有用户、角色、权限、部门；查看全部日志 | 平台初始化、权限治理、安全审计 |
| 系统运维 | 管理用户账号、查看日志、维护部门 | 日常账号维护、故障排查 |
| 空间管理员 | 查看本部门用户与部门信息 | 了解团队人员与组织关系 |

## 3. 功能需求清单

### 3.1 登录功能

| 编号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| FR-01 | 用户名 + 密码登录 | P0 | 标准登录方式，所有用户可用 |
| FR-02 | 手机号 + 密码登录 | P0 | 需先绑定手机号 |
| FR-03 | 邮箱 + 密码登录 | P1 | 需先绑定邮箱 |
| FR-04 | 初始管理员账号 | P0 | 系统内置 admin / onto12345678!，首次登录使用初始密码时强制修改密码，不可跳过 |
| FR-05 | 记住登录状态 | P1 | 勾选后下次免登录 |
| FR-06 | 登录失败锁定 | P1 | 连续失败 5 次锁定账号 30 分钟 |
| FR-06.1 | 图形验证码 | P0 | 登录时须输入 4 位图形验证码（字母 + 数字随机组合）；验证码图片点击可刷新；验证码不区分大小写；每次刷新生成新验证码，旧验证码立即失效；验证码校验不通过时不消耗登录失败次数 |
| FR-06.2 | 退出登录 | P0 | 用户可主动退出登录；退出后清除 Token 与登录态，仅跳转至登录页面；退出登录入口在顶栏用户头像下拉菜单中，所有已登录页面均可访问 |
| FR-06.3 | Token 有效期管理 | P0 | 采用双 Token 机制：Access Token 有效期默认 2 小时，Refresh Token 有效期默认 7 天；勾选"记住我"时 Refresh Token 延长至 30 天；Access Token 过期后前端自动使用 Refresh Token 刷新，Refresh Token 过期后强制重新登录 |
| FR-06.4 | 单点登录互踢 | P1 | 同一账号在其他设备登录时，旧设备是否强制下线；通过配置项 `prism.security.login.single-session` 控制（默认 `false` 允许多端在线）；开启后旧设备收到互踢通知并跳转至登录页 |
| FR-06.5 | 密码复杂度校验 | P0 | 所有密码设置/修改场景均须校验：长度 8-20 位，必须包含大写字母、小写字母、数字、特殊字符；前后端同步执行 |
| FR-06.6 | 密码过期策略 | P2 | 密码使用超过 N 天后强制修改；通过配置项 `prism.security.password.expire-days` 设置（默认 `0` 表示关闭）；开启后密码过期用户登录时弹出"修改密码"弹窗 |
| FR-06.7 | 忘记密码 | P1 | 用户点击"忘记密码"后，通过已绑定的手机号或邮箱接收验证码，验证通过后重置密码为 `onto12345678!`，首次登录后强制修改密码 |

## 4. 页面与交互说明

### 4.1 登录页面（system/login.html）

**页面路径**：`/system/login.html`

**布局**：
- 独立页面，无导航栏和侧边栏
- 居中卡片式布局，深色渐变背景
- 顶部品牌标识（Prism logo + 产品名称 + 标语）
- 登录卡片内包含三种登录方式的 Tab 切换
- 每种登录方式的密码输入框下方均包含验证码输入框（左侧输入框 + 右侧图形验证码图片）

**交互**：
1. 点击 Tab 切换登录方式（用户名 / 手机号 / 邮箱）
2. 页面加载时自动生成 4 位图形验证码（字母 + 数字随机组合），绘制于验证码图片上并叠加干扰线/噪点
3. 输入账号、密码与验证码后点击"登录"按钮或按 Enter 键；前端先校验验证码（不区分大小写），校验不通过则提示"验证码错误"并自动刷新验证码，不提交登录请求、不消耗登录失败次数
4. 点击验证码图片可手动刷新验证码，旧验证码立即失效
5. 切换登录方式时自动刷新验证码
6. **首次登录强制修改密码**：当后端检测到用户使用初始密码（`pwd_update_time` 为空）登录时，返回首次登录标记；前端弹出不可关闭、不可跳过的"强制修改密码"弹窗，用户必须输入当前密码、新密码（需满足密码复杂度：至少 8 位，含大写字母、小写字母、数字、特殊字符）并确认新密码，提交成功后方可进入系统
7. 非首次登录：登录成功直接跳转至首页（index.html）
8. 底部展示初始管理员账号提示（admin / onto12345678!）
9. "记住我"勾选框：勾选后 Refresh Token 有效期延长至 30 天（参见 FR-06.3）
10. "忘记密码"链接：点击后跳转忘记密码流程页面，用户选择手机号或邮箱接收验证码，验证通过后重置密码为 `onto12345678!`（参见 FR-06.7）

**页面路径**：`/system/sys-users.html`

**布局**：
- 顶部统计卡片（用户总数、启用用户、停用用户、今日登录）

- 重置密码：重置后密码恢复为 `onto12345678!`，用户下次登录时触发强制修改密码流程（admin 提示通过安全渠道重置）

**弹窗**：
- 新增/编辑用户弹窗：用户名、姓名、手机号、邮箱、部门（下拉）、状态
- 用户详情弹窗：完整信息展示
- 分配角色弹窗：角色复选列表（超级管理员仅 admin 可分配）
- 分配部门弹窗：部门单选列表
- 重置密码弹窗：确认重置按钮（重置后密码统一恢复为 `onto12345678!`，用户下次登录强制修改）
- 批量导入弹窗：模板下载链接 + 文件上传区（.xlsx，不超过 10MB）+ 导入结果明细（成功数、失败数、失败原因）
- 批量导出：点击按钮后按当前筛选条件下载 Excel 文件

## 7. 非功能需求

### 7.1 安全

| 类别 | 要求 |
|---|---|
| 密码策略 | 8-20 位，必须包含大写字母、小写字母、数字和特殊字符；首次登录使用初始密码时强制修改，不可跳过；密码过期策略可选开启（默认关闭） |
| 初始密码 | 统一为 `onto12345678!`（适用于系统内置管理员、新增用户、密码重置、忘记密码场景），首次登录强制修改 |
| 登录锁定 | 连续失败 5 次锁定 30 分钟 |
| 超级管理员保护 | admin 账号不可停用、用户名不可修改、密码需通过安全渠道重置 |
| 超级管理员角色 | 仅可分配给 admin 用户，其余用户不可分配该角色 |
| 内置角色保护 | 超级管理员、系统运维、空间管理员三个内置角色不可删除、不可停用 |
| 密码存储 | 后端使用 BCrypt 加盐哈希存储，禁止明文 |
| Token 管理 | 采用双 Token 机制：Access Token（默认 2 小时）+ Refresh Token（默认 7 天）；勾选"记住我"时 Refresh Token 延长至 30 天；Access Token 过期后前端自动静默刷新，Refresh Token 过期后强制重新登录；所有 Token 有效期均可通过 `application.yaml` 配置 |
| 单点登录互踢 | 同一账号多设备登录时，可通过配置项 `prism.security.login.single-session` 控制是否强制下线旧设备（默认关闭） |
| 忘记密码 | 通过已绑定的手机号或邮箱接收验证码，验证通过后重置密码为初始密码，首次登录强制修改 |

### 7.2 权限

| 类别 | 要求 |
|---|---|
| 菜单权限 | 目录 / 菜单控制导航可见性，无权限不展示 |
| 按钮权限 | 按钮 / 接口级鉴权，权限标识如 `system:user:create` |
| 空间数据权限 | 角色可配置可见空间范围：全部空间 / 本部门及子部门 / 本部门 / 仅自己创建 / 自定义 |
| 日志查看权限 | 审计日志仅超级管理员和系统运维可查看 |

### 7.3 性能

| 类别 | 要求 |
|---|---|
| 用户列表 | 1000 条数据内分页响应 < 200ms |
| 权限树渲染 | 100 个节点内渲染 < 100ms |
| 日志查询 | 180 天内日志查询响应 < 2s（需合理索引） |
| 登录响应 | 登录验证 < 500ms |

### 7.4 数据隔离

- 系统管理为平台级功能，数据不按工作空间隔离。
- 用户、角色、部门为全局共享资源，所有工作空间共用。
- 空间数据权限决定角色可见的工作空间范围。

## 8. 可配置项（application.yaml）

> 以下为系统管理模块涉及的 `application.yaml` 可配置项，便于运维人员按需调整而无需重新编译。

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `prism.log.retention.days` | int | `180` | 日志保留天数。定时任务每日凌晨扫描，删除超出此天数的审计日志、登录日志、执行日志记录。设为 `0` 表示不清理（永久保留）。 |
| `prism.security.login.max-fail-count` | int | `5` | 连续登录失败次数上限，超出后账号自动锁定。 |
| `prism.security.login.lock-minutes` | int | `30` | 账号锁定时长（分钟）。 |
| `prism.security.jwt.access-expire-hours` | int | `2` | Access Token 有效期（小时）。 |
| `prism.security.jwt.refresh-expire-days` | int | `7` | Refresh Token 有效期（天）。 |
| `prism.security.jwt.remember-refresh-expire-days` | int | `30` | 勾选"记住我"时 Refresh Token 有效期（天）。 |
| `prism.security.login.single-session` | boolean | `false` | 是否开启单点登录互踢。`true` 时同一账号仅允许最新一次登录有效，旧设备强制下线。 |
| `prism.security.password.initial` | String | `onto12345678!` | 新增用户与密码重置的初始密码。 |
| `prism.security.password.expire-days` | int | `0` | 密码过期天数。密码使用超过此天数后登录强制修改。设为 `0` 表示关闭密码过期策略。 |
| `prism.security.password.min-length` | int | `8` | 密码最小长度。 |
| `prism.security.password.max-length` | int | `20` | 密码最大长度。 |

**示例配置片段**：

```yaml
prism:
  log:
    retention:
      days: 180          # 日志保留天数，0 表示永久保留
  security:
    login:
      max-fail-count: 5  # 连续失败锁定次数
      lock-minutes: 30   # 锁定时长（分钟）
      single-session: false  # 是否开启单点登录互踢
    jwt:
      access-expire-hours: 2           # Access Token 有效期（小时）
      refresh-expire-days: 7           # Refresh Token 有效期（天）
      remember-refresh-expire-days: 30 # 记住我时 Refresh Token 有效期（天）
    password:
      initial: "onto12345678!"   # 初始密码（重置密码亦使用此值）
      expire-days: 0             # 密码过期天数，0 表示关闭
      min-length: 8              # 密码最小长度
      max-length: 20             # 密码最大长度
```

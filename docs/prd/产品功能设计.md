## 1. 产品概述

### 1.1 产品定位

本体语义平台是面向企业数据语义化的中台产品：以**本体（Ontology）**为核心，将分散在多源异构系统中的数据（Doris 数仓、NebulaGraph 图数据库等）映射为可理解的业务对象（类）、属性与关系，并在此之上提供数据查询、规则校验、动作写回、函数计算、工作流编排与开放 API 能力。

### 1.2 目标用户

| 角色 | 典型用户 | 核心诉求 |
|---|---|---|
| 超级管理员 | 平台运维 | 平台级账号、空间与权限治理 |
| 空间管理员 | 业务/数据团队负责人 | 创建空间、分配成员、管理空间内全部资源 |
| 本体建模员 | 数据架构师 / 业务专家 | 建模业务对象、属性、关系与规则 |
| 数据工程师 | 数据开发 | 数据接入、Pipeline 开发与运维 |
| 数据分析师 / 应用开发 | 分析师、业务系统开发 | 查询对象数据、调用 API / Workflow / Skill |

### 1.3 核心价值

1. **语义统一**：以本体图谱统一业务概念，数据集字段 → 本体属性 → 业务语义三层贯通。
2. **数据即对象**：数据不再是表，而是可点查、可关联、可写回的业务对象。
3. **安全内建**：密级标记、行列级权限、加密、脱敏在本体层统一生效。
4. **能力开放**：对象点查 / 关联查询 / 动作 / 函数以 API Key、Workflow、Skill 形式对外开放。

## 2. 总体设计

### 2.1 核心概念模型

```
平台（Platform）
 └─ 工作空间（Workspace）                ← 顶层隔离单元
     ├─ 本体资产：类 / 接口 / 抽象类 / 枚举类、属性、关联关系、值约束、动作、函数
     ├─ 数据资产：数据源、数据集、Pipeline
     ├─ 安全策略：标记、数据权限、加密、脱敏
     ├─ 应用资产：API Key、Workflow、Skills
     └─ 审计数据：操作日志、运行与调用统计
```

- **工作空间**是资源与权限的顶层隔离边界，跨空间数据默认不可互访。
- **类（Object Type）**可实例化为对象，映射到主数据集；**接口（Interface）**定义可被多类实现的属性契约；**抽象类**作为公共父类；**枚举类**提供受限取值集合。
- **类属性**分五种：主键属性、普通属性、对象属性（Link）、共享属性、衍生属性、控制属性（权限管控）。

### 2.2 角色与权限模型

| 能力 | 超级管理员 | 空间管理员 | 本体建模员 | 数据工程师 | 只读访客 |
|---|---|---|---|---|---|
| 创建 / 删除工作空间 | ✔ | ✔ | ✘ | ✘ | ✘ |
| 空间成员 / 角色分配 | ✔ | ✔（本空间） | ✘ | ✘ | ✘ |
| 本体资产建模 | ✔ | ✔ | ✔ | ✘ | 只读 |
| 数据源 / 数据集 / Pipeline | ✔ | ✔ | ✘ | ✔ | 只读 |
| 安全策略管理 | ✔ | ✔ | ✘ | ✘ | ✘ |
| 应用管理（Key / Workflow / Skill） | ✔ | ✔ | 只读 | 只读 | ✘ |
| 审计查看 | ✔ | ✔ | 本域 | 本域 | ✘ |

权限粒度支持到**菜单 → 按钮 / 接口**两级（权限标识如 `ontology:type:publish`），空间角色在各空间内独立配置。

## 3. 平台管理

### 3.1 工作空间管理（platform/workspace.html）

**功能描述**：工作空间是本体资产、数据、应用与安全策略的顶层隔离单元。仅超级管理员 / 空间管理员可创建。

**功能点**：

| 功能 | 说明 |
|---|---|
| 空间 CRUD | 新建（名称、唯一编码、描述、空间管理员、启用状态）、编辑、停用；删除需二次确认且建议仅超级管理员可操作 |
| 成员分配 | 空间内分配**用户 / 角色 / 部门**三个维度；支持穿梭框批量添加移除、按部门带默认角色 |
| 空间角色管理 | 空间内置角色（空间管理员、本体建模员、数据工程师、只读访客），支持新建空间级自定义角色并配置按钮级权限 |
| 空间概览 | 空间总数、成员总数、本体资产总数、活跃空间（30 天）统计卡片 |
| 空间切换 | 顶栏空间切换器，切换后空间内所有页面数据按当前空间过滤 |

**约束**：空间编码创建后不可修改；删除空间需先确认空间内无已发布资产或做归档处理。

### 3.2 系统管理（platform/system.html）

**功能描述**：平台级的用户、角色、部门与权限管理。

| 子功能 | 说明 |
|---|---|
| 用户管理 | 用户新增 / 编辑 / 停用 / 重置密码；维护姓名、账号、所属部门、全局角色、邮箱；支持按部门与状态筛选，查看用户所属空间 |
| 角色管理 | 全局角色与空间角色两类；支持配置菜单 / 按钮权限、查看角色成员；内置角色（超级管理员、系统运维、空间管理员）不可删除 |
| 部门管理 | 部门树维护（无限层级、排序、部门主管）；部门可关联多个空间并设置默认角色 |
| 权限管理 | 左侧菜单树（支持到三级菜单），右侧维护该菜单下需鉴权的按钮 / 接口权限标识，如 `ontology:type:create`、`ontology:data:query` |

## 4. 本体资产管理

> 参考 Palantir Foundry：Object Types、Link Types、Shared Property Types、Value Type Constraints、Action Types、Functions。

### 4.1 本体图谱（ontology/ontology-graph.html）

**功能描述**：本体建模的核心页面，管理类 / 接口 / 抽象类 / 枚举类及其属性、数据映射与对象数据查询。

**功能点**：

1. **类管理**
   - 支持四种类型：**类（Object Type，可实例化）**、**接口（Interface）**、**抽象类（Abstract）**、**枚举类（Enum）**。
   - 类目树按业务域组织（生产域 / 质量域 / 资产域 / 基础类型）。
   - 类定义含：显示名、API 名称、继承 / 实现（implements 接口）、主键属性、标题属性、主数据集、版本（草稿 / 已发布）、描述。
   - **版本管理**：编辑生成草稿版本，提交发布需审批，发布后版本留痕。
   - **列表 / 图谱双视图**：图谱视图以 SVG 关系图展示类与关系（实线=对象链接、虚线框=接口、橙色=枚举类）。
2. **属性管理**（类详情抽屉）

   | 属性种类 | 说明 | 示例 |
   |---|---|---|
   | 主键属性 | 对象唯一标识，必填 | `equipment_id` |
   | 普通属性 | 基础数据字段 | `equipment_name` |
   | 对象属性 | 指向其他对象类型的 Link | `line → ProductionLine` |
   | 共享属性 | 引用空间级共享属性定义 | `asset_no` |
   | 衍生属性 | 由函数计算得出，不可直接写入 | `yield_rate = calcYield()` |
   | 控制属性 | 受权限管控的敏感属性 | `unit_cost` |

3. **数据映射**：将类 / 属性映射到数据源数据集与字段，支持 Doris（实时 CDC / T+1 批量）与 NebulaGraph（图边关系），提供映射向导与映射校验。
4. **对象数据查询**：按类 + 过滤条件在线查询对象实例数据（Limit 控制），展示返回条数、耗时、数据来源。
5. **控制属性权限**（Mandatory Control Properties）：将属性标记为控制属性，配置可见角色（如成本类属性仅空间管理员 / 成本分析员可见），查询时统一生效。

### 4.2 关联关系（ontology/ontology-relations.html）

**功能描述**：维护对象类型之间的语义关系（Link Types）与 RDF 定义。

| 功能 | 说明 |
|---|---|
| 关系定义 | 源 / 目标对象类型、正向与反向语义（如 `uses / used_by`）、源 / 目标基数（1..1、1..n、0..n） |
| 实现方式 | 外键关联（FK）、多对多关联表、图边（NebulaGraph Edge）、衍生关联（函数计算） |
| RDF 维护 | 命名空间管理（oo / rdf / rdfs / owl）；Turtle 语法编辑器维护三元组与 OWL ObjectProperty 定义，带语法校验；关系可配置 RDF 谓词（如 `oo:uses`） |
| 图谱定位 | 从关系列表一键在图谱视图中高亮该关系 |

### 4.3 共享属性（ontology/ontology-shared-props.html）

**功能描述**：跨对象类型复用的属性定义（Shared Property Type），一处修改、多处生效。

- 定义：属性名称、API 名称、数据类型、值约束、说明。
- **关联管理**：穿梭框将共享属性关联到多个对象类型；关联时可选「复用已有字段映射」或「在各类型中重新映射」。
- 关联视图：查看每个关联类型的类型内属性名、数据集字段映射与同步状态。
- 约束：已关联的共享属性不可删除，需先解除全部关联；属性类型修改需走版本变更流程。

### 4.4 枚举类（ontology/ontology-enums.html）

- 枚举值定义：`值 | 显示名 | 排序`，支持启用 / 停用（已使用的枚举值建议停用而非删除）。
- 数据来源：手工维护或从数据集字典表同步。
- 引用管理：展示引用该枚举的对象属性（如 `Equipment.status`），供属性定义与动作参数复用。

### 4.5 值约束规则（ontology/ontology-constraints.html）

**功能描述**：为对象属性定义取值合法性约束（Value Type Constraints）。

| 配置项 | 取值 |
|---|---|
| 约束类型 | 正则表达式、数值范围、枚举引用、外键引用（值必须存在于某数据集）、唯一性、非空必填、自定义函数校验 |
| 校验时机 | 写入时（强约束）、Pipeline 校验（准实时）、查询时（弱约束） |
| 失败动作 | 拒绝写入、写入隔离区并告警、仅记录审计日志 |

- 运行监控：今日校验次数、拦截脏数据数、整体通过率；支持规则试运行与全量回刷校验。
- 拦截记录明细：时间、规则、对象 / 记录、非法值、处理动作。

### 4.6 动作（ontology/ontology-actions.html）

**功能描述**：对本体对象的安全写回操作（Action Types），是平台从「只读分析」走向「业务闭环」的关键。

- **动作类型**：对象写入（创建 / 编辑 / 删除）、调用函数、发送通知、调用外部系统 API。
- **参数定义**：支持对象引用类型（如 `equipment: Equipment`）、枚举类型，可配置必填与约束。
- **提交校验**：绑定值约束规则，提交前全量校验并展示结果。
- **审批流**：无审批直接执行 / 需空间管理员审批 / 自定义审批流。
- **副作用**：执行后事件（创建关联对象、发送通知、触发衍生属性重算）。
- **试运行**：填参 → 校验 → 预览执行计划，试运行不实际写库。
- 调用日志与调用量统计（今日 N 次）。

### 4.7 函数（ontology/ontology-functions.html）

- **编写**：在线编辑 Python / SQL（nGQL）函数，函数签名作用于本体对象类型，如 `calcEquipmentYield(equipment: Equipment, windowDays: Integer = 30): YieldResult`；沙箱执行。
- **复用场景**：衍生属性计算、动作逻辑、Workflow 节点、开放 API。
- **质量**：单元测试管理（用例通过率）、版本管理、在线调试。
- **监控**：调用量 / 失败次数趋势（近 7 天）、被引用场景清单。

## 5. 数据管理

### 5.1 数据源管理（data/data-sources.html）

- 支持数据源类型：**Doris**（MySQL 协议）、**NebulaGraph**、Kafka、API 数据源（可扩展）。
- 连接配置：地址、账号、密码（加密存储于平台凭据库）、连接测试。
- 数据源绑定密级标记；展示数据集数量与连接健康状态（连接正常 / 消费者组延迟）。

### 5.2 数据集管理（data/data-datasets.html）

- 注册数据集：选择数据源 → 选择库表 → 设置说明、同步策略、密级。
- 数据集列表：数据量、字段数、同步策略（实时 CDC / 每日 T+1 / 分钟级）、密级、健康状态（延迟告警）。
- 字段管理：字段类型、说明、密级 / 标记、**映射到本体属性**的关系展示。
- **血缘视图**：数据集与 Pipeline 之间的血缘关系图。

### 5.3 Pipeline 管理（data/data-pipeline.html）

按四大类组织：

| 类别 | 典型任务 | 示例 |
|---|---|---|
| 数据集成 | CDC / 批量同步 / 图谱构建 | `pl-equipment-cdc`：Flink CDC → Doris |
| 数据开发 | SQL 清洗加工分层 | `pl-quality-clean`：ODS → DWD |
| 数据质量 | 值约束规则回刷校验 | `pl-dq-check`：失败进入隔离区并告警 |
| 数据治理 | 元数据血缘采集 | `pl-lineage` |

- DAG 编排画布：节点拖拽、依赖连线、手动 / 定时调度配置。
- 运行实例时间线：成功 / 部分失败状态、时长、处理数据量；失败自动通知责任人。

### 5.4 数据探查（data/data-explore.html）

- 面向数据工程师 / 分析师的 **只读 SQL 探查**（含 NebulaGraph nGQL）。
- 编辑器支持语法高亮、格式化、执行计划、保存脚本与片段。
- 结果区：行数、耗时、扫描量、**自动脱敏提示**（按当前用户权限脱敏）；支持提交为数据集、导出 CSV。
- 查询历史留痕并进入审计。

## 6. 安全管理

> 安全策略以「标记」为载体，在本体层与数据层统一生效。

### 6.1 标记管理（security/sec-marks.html）

- 三类标记：密级标记（L1 公开 / L2 内部 / L3 秘密 / L4 机密）、业务标记（PII / FIN 财务 / 商密）、自定义标记。
- 每个标记配置默认策略：仅授权角色可见、可见但脱敏、可见但不可导出。
- 打标范围：数据源 / 数据集 / 字段 / 本体类 / 属性 / 动作。

### 6.2 数据权限（security/sec-permissions.html）

- **行级权限**：过滤表达式（如 `domain = 'QUALITY'`、`line IN (user.dept_lines)` 动态按部门）。
- **列级权限**：属性 / 字段维度授权，与本体「控制属性权限矩阵」联动。
- 授权对象：角色 / 部门动态规则。
- **校验优先级**：对象权限（本体图谱）> 数据集权限 > 字段 / 标记策略，全部通过才放行，命中即记录审计。

### 6.3 加密（security/sec-encryption.html）

- 字段级加密配置：算法（AES-256-GCM / SM4 国密）、KMS 密钥、加密范围（共享属性 / 字段）、模式（存储加密+查询解密 / 仅存储加密）。
- 密钥管理：主密钥轮换周期（90 天）、待轮换告警、数据密钥按数据集 / 字段隔离。

### 6.4 脱敏（security/sec-masking.html）

- 动态脱敏规则：脱敏字段（可按标记批量，如 `*PII`）、算法（掩码 / 区间桶 / 姓氏保留 / SHA-256 哈希）、豁免角色。
- 查询时按身份实时脱敏，不改变底层数据；提供按角色维度的脱敏效果预览与试脱敏。

## 7. 应用管理

### 7.1 API Key（application/app-apikeys.html）

- 为外部应用（MES、BI、机器人等）签发空间内访问凭证：名称、调用方、**Scope 授权**（对象点查 / 关联查询 / 动作执行 / Workflow 调用 / 数据探查）、有效期、限流（QPS）、IP 白名单。
- Key 掩码展示，生成仅明文展示一次；支持轮换、吊销、删除。
- 调用统计与 REST 调用示例（Bearer Token 访问对象点查 / 关联查询接口）。

### 7.2 Workflow 编排（application/app-workflow.html）

- 可视化画布编排，节点类型：**对象点查、关联查询、规则判断、动作执行、函数、条件分支、通知、HTTP 调用**。
- 触发方式：定时、API 触发、动作触发（事件驱动）。
- 版本管理：草稿 → 发布（vN），试运行不生效；执行历史含处理对象数与告警触发数。

### 7.3 Skills（application/app-skills.html）

- Skill 是基于本体资产与函数封装的高层能力单元（如「良率分析」「故障根因推荐」「自然语言查数 NL2Object」）。
- 来源：Skill 市场安装 / 本地注册；状态：已启用 / 审核中 / 已停用。
- 每个 Skill 绑定其依赖的函数 / 关联查询 / API 能力，并统计调用量。

## 8. 审计管理

### 8.1 审计日志（audit/audit-logs.html）

- 全量记录：操作者（用户 / API Key / 系统）、模块、操作内容、类型（查询 / 写入 / 变更 / 鉴权 / 运行）、结果（通过 / 拒绝 / 已留痕）。
- 多维筛选：模块、类型、时间范围、关键词；支持导出 CSV 与保留策略配置（默认 180 天）。
- 重点覆盖：越权拒绝事件、敏感变更（安全策略 / 权限矩阵修改）、动作执行与工单生成。

### 8.2 本体资产统计（audit/audit-assets.html）

- 资产数量统计：对象类 / 接口与抽象类 / 枚举类 / 属性 / 动作与函数。
- 对象实例数 Top 排行；资产活跃度（近 30 天被查询次数与涨跌）。
- 资产维护情况：按资产域统计最近变更人与草稿版本。

### 8.3 Pipeline 运行（audit/audit-pipelines.html）

- 运行统计：今日运行次数、成功率、平均时长、失败 / 隔离数。
- 近 7 天运行趋势（成功 / 失败对比柱状图）。
- 失败 / 隔离明细：实例号、失败原因、隔离区入口、重跑操作。

### 8.4 应用调用（audit/audit-apps.html）

- API 调用统计：今日调用量、鉴权失败、P95 延迟、限流触发。
- 按调用方（API Key）与按接口类型（点查 / 关联查询 / 动作 / Workflow）两个维度统计。
- Workflow / Skill 调用排行：调用量、成功率、平均耗时。

## 9. 关键业务流程

### 9.1 本体建模与数据映射流程

```
创建类 → 定义属性（引用共享属性 / 枚举 / 控制标记）
      → 定义关联关系（语义 + 基数 + 实现方式）
      → 配置数据映射（类 ↔ 数据集字段）
      → 配置值约束规则 → 提交发布（审批）→ 版本生效
```

### 9.2 动作执行流程

```
用户/应用发起动作 → 参数校验（值约束 + 自定义规则）
   → 通过：审批流（如需）→ 执行（对象写入 / 函数 / 外部 API）
        → 副作用（创建关联对象、通知、衍生属性重算）→ 审计留痕
   → 不通过：返回校验结果，拒绝执行
```

### 9.3 数据查询与安全校验流程

```
查询请求（页面 / API Key / Workflow）
   → 鉴权（Key 有效性、Scope、IP、限流）
   → 权限校验（对象权限 → 数据集权限 → 行级过滤 → 列级 / 控制属性 → 标记策略）
   → 加密解密 / 动态脱敏 → 返回结果 → 审计记录
```

### 9.4 数据接入流程

```
新建数据源（测试连接）→ 注册数据集（同步策略、密级标记）
   → 编排 Pipeline（集成 / 开发 / 质量 / 治理）
   → 数据集字段映射到本体属性 → 对象数据可查询 / 可关联
```

## 10. 非功能需求

| 类别 | 要求 |
|---|---|
| 多租户隔离 | 工作空间级资源与权限隔离，跨空间访问默认拒绝并可审计 |
| 权限粒度 | 菜单 → 按钮 / 接口（权限标识）→ 数据（行 / 列 / 标记）三级 |
| 安全合规 | 凭据加密存储（KMS）、国密算法支持（SM4）、密钥定期轮换、动态脱敏不影响底层数据 |
| 可观测性 | 全量审计日志（默认保留 180 天）、Pipeline 与 API 调用指标（成功率 / P95 / 限流） |
| 版本与发布 | 本体类、函数、Workflow 均采用草稿 → 发布版本化机制，变更留痕 |
| 数据质量 | 值约束三层校验时机（写入 / Pipeline / 查询），失败数据进入隔离区可追溯、可重放 |
| 扩展性 | 数据源类型、脱敏算法、Skill 市场均按插件化扩展设计 |
